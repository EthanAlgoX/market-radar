# 工作台功能流程

Market Radar 将搜集新信息、阅读本地内容、分析行情分成清晰流程。界面默认英文，界面语言与资讯阅读语言相互独立。

## 导航与链接

| 页面 | 用途 |
| --- | --- |
| 资讯库 | 搜索与筛选所有本地收录频道，也可继续搜集关键词相关信息 |
| 我的关注 | 阅读关注作者、账号订阅与已启用 RSS 的内容 |
| 为我推荐 | 阅读已连接账号的 X For You 或 Reddit API 首页 |
| 已收藏 | 回看来自任意频道的收藏 |
| 行情与信号 | 管理自选，刷新 K 线，核对规则信号 |
| 设置 | 账号、研究设置、RSS 来源、翻译 API、来源状态 |

切换资讯频道会清除之前的查询、主题与来源筛选。资讯库和已收藏支持主题筛选；我的关注与为我推荐保留没有命中研究关键词的内容。

URL 的 hash 记录页面、频道及本地筛选。浏览器前进、后退可恢复这些条件，刷新有效链接也可回到该工作区。本地服务运行后，可使用：

- [Bitcoin 关键词研究](http://localhost:8787/#/news?topic=crypto&q=Bitcoin)
- [我的关注](http://localhost:8787/#/news?channel=following)
- [已收藏的 Reddit 内容](http://localhost:8787/#/news?channel=bookmarked&source=reddit&sort=latest)
- [行情工作台](http://localhost:8787/#/markets)
- [翻译 API](http://localhost:8787/#/settings?tab=translation)
- [来源状态](http://localhost:8787/#/settings?tab=health)

查询会进行 URL 编码，未知路径与选项回落到安全默认值。链接不记录选中的阅读条目、行情标的或未保存的设置草稿。

在当前页面内导航，包括进入翻译 API 设置再返回时，会保留行情标的与分析标签；刷新浏览器后重置行情选择。本地查询的连续输入合并为一个历史步骤。

## 搜集与筛选关键词资讯

1. 打开 **资讯库**，在采集框输入查询，点击 **搜集资讯**。框下方列出本次实际采集来源。
2. 任务显示各来源进度与失败情况；一个来源失败不会丢弃其他来源的成功内容。
3. 本地列表按刚提交的查询筛选。点击筛选标签或 **清除筛选** 可扩大结果范围。
4. 通过 **搜索本地资讯库**、主题、来源与排序控件查看已有内容。**刷新本地列表** 只重新读取本地记录，不采集新帖子。

关键词采集使用 Google News、Hacker News、已启用 RSS 和已连接账号。本地来源筛选不会限制或改变采集来源。RSS 中未匹配关键词的内容也可通过我的关注独立读取。查询支持财经别名、短语、括号与 `OR`、`AND`、`NOT`。

侧栏的已保存关键词会筛选本地资讯库，并准备采集查询；采集框内的快捷词仅填入查询。两种快捷入口都需要点击 **搜集资讯** 才发起网络采集。**导出全部** 导出本地收录内容，而不是当前筛选结果；导出 API 支持 JSON 与 CSV。

## 我的关注与账号信息流

在 **设置 → 账号** 授权自己的 X 或 Reddit。X 使用隔离浏览器登录；Reddit 需要获得 API 访问权限的应用。可同步来源提供的关注或订阅名单，也可在 **研究设置** 填写指定作者。

点击 **拉取关注**，独立搜集关注人与订阅内容，不要求匹配关键词。没有个人账号时，已启用 RSS 订阅也可使用此频道；先在 **设置 → RSS 来源** 添加或启用，并点击 **保存 RSS 来源**。

在为我推荐点击 **拉取推荐**，请求已连接账号的信息流。此频道不使用 RSS 或公开新闻。X 通过 Twikit 的非官方会话接口访问，平台变更或会话过期可能导致不可用。Reddit 使用 OAuth `best`，可能与网站推荐不同；同步订阅也未必能复现网站完整关注名单。两种来源都受平台、分页与请求预算限制。只填写 RSSHub 地址不代表本人首页可用。

个人账号流程具备离线回归测试；真实账号采集仍取决于你的授权、会话与来源访问权限。

## 阅读、收藏与翻译

点击标题打开阅读区并标记已读。来源、作者、发布时间与原链接保留可见。**整理内容** 区分原文摘录与可选 AI 摘要。**原始文本** 展示采集返回的文字；**读取文章正文** 按需尝试提取可访问文章。部分来源只有标题或摘录。Reddit 与 Hacker News 可按需加载有限评论。

收藏后可在已收藏继续阅读。该页面提供本地筛选与刷新，不包含采集动作。

顶栏 **中文 / English** 切换内置界面文案，不调用 LLM。资讯区 **资讯语言 → 中文** 请求内容翻译，行情相关资讯也使用同一阅读偏好。浏览器分别记住两项设置，仅切换界面语言不会发起翻译。

内容翻译需要在 **设置 → 翻译 API** 配置自己的 API，或使用可用的环境备用配置。默认 DeepSeek Flash，也支持 OpenAI 兼容 Chat Completions 服务。未配置时提示前往设置，并保留原文。翻译会将相关文字发送给你配置的服务。译文按原文版本、服务商与模型缓存，失败保留原文并可重试。只有该条译文就绪时，阅读区才标记为 **中文译文**，原始文本仍可查看。

AI 摘要是研究设置中的独立可选功能，启用摘要不会同时启用翻译。

## 查看 K 线与信号

添加支持的标的后，刷新此标的或全部自选；只添加不会获取行情。自选最多 20 个，图表最多展示 180 根 K 线，支持 Binance USDT 现货小时线，以及限定来源范围内的美股、港股、A 股日线。

图表下方提供：

| 标签 | 核对内容 |
| --- | --- |
| 信号 | 已收盘规则事件；展开核对观测值、规则证据、确认时间与来源 |
| 相关资讯 | 按标的及标注的时间窗口匹配最多 8 条本地资讯，可继续前往资讯库筛选或搜集 |
| 数据与规则 | K 线时间、接收时间、币种、成交量单位、复权、覆盖范围、质量说明与规则要求 |

数据警告保留在图表附近，不会因切换标签而隐藏。来源失败保留已有行情；过期信号标为历史记录，待重新核验状态明确显示。新闻与行情时间接近不代表因果关系，应用不会执行交易。来源与有限历史窗口说明见 [README 行情范围](../README.zh-CN.md#行情与信号)。

## 设置与保存

研究设置、RSS 来源、RSSHub 地址与翻译 API 分别保存，一个区域的保存不会提交其他区域的待确认修改。未保存圆点与待保存列表标明位置，**放弃修改** 仅重置对应区域。失败在设置旁说明并保留输入。同步账号名单只更新未编辑字段，保留本地修改。

在设置分类之间切换，或返回资讯与行情时，草稿保留在内存中。刷新或关闭浏览器前应保存，未保存草稿不会跨这两种操作保留。翻译密钥在本地加密保存，配置响应不返回密钥。页面保存 API 后立即生效；环境变量变更需要重启服务。

**来源状态** 分别显示最近尝试与成功采集，说明部分失败或连接不可用。它描述资讯采集来源；行情另有质量、刷新与来源状态。

## 流程与 API 对照

以下路径属于本地服务，接口定义见 [localhost:8787/docs](http://localhost:8787/docs)。

| 流程 | API |
| --- | --- |
| 本地列表与筛选 | `GET /api/items` |
| 采集与进度 | `POST /api/collect`、`GET /api/jobs/{id}` |
| 已读与收藏 | `PATCH /api/items/{id}` |
| 正文、评论、可选摘要 | `POST /api/items/{id}/content`、`/discussion`、`/summarize` |
| 设置与 RSS 预设 | `GET/PUT /api/settings`、`GET /api/source-presets` |
| 账号授权与同步 | `/api/connections/x/*`、`/api/connections/reddit/*` |
| 翻译配置与任务 | `/api/translation/config`、`/api/translation/status`、`POST /api/translate`、`GET /api/translation/jobs/{id}` |
| 自选、K 线与信号 | `/api/market/overview`、`/watchlist`、`/refresh`、`/jobs/{id}`、`/instruments/{id}` |
| 导出所有收录内容 | `GET /api/export?format=json` 或 `format=csv` |
