# Market Radar 0.2 升级说明

0.2 完善本地采集、来源追溯与阅读流程。应用仍由本机 FastAPI 进程、React 前端和 SQLite 组成；启动方式不变，安装依赖后运行 `./start.sh` 或 `npm start`。

## 采集任务与来源状态

采集请求先持久保存到 SQLite，再由本地工作协程执行。相同的活动请求复用已有任务，队列有数量上限。重启后，带有完整请求的中断任务重新排队，已完成或部分完成的来源保留结果，未完成来源继续执行；此前保存的资讯仍可阅读。旧版本缺少请求信息的中断任务会标记失败，需要重新提交。

不同来源并行执行，同一来源串行，并限制总并发。公开 RSS 另有订阅并发、同域并发与请求间隔限制；暂时性网络故障、限流和部分服务端错误只进行有限重试。每个来源独立显示等待、运行、重试、完成、部分完成或失败，以及收到、新增、更新、重复、范围有限等信息。一个来源失败不会撤销其他来源已保存的结果。

这是本地单后端进程的耐久队列。恢复可能重新请求未完成来源的有限窗口，由稳定身份与去重处理再次收到的条目；它不提供多节点调度、分布式租约或完整历史分页回补。自动更新仍需本地服务持续运行。

## RSS、身份与来源追溯

- RSS GUID / Atom ID 与订阅身份共同构成稳定条目标识；缺失时使用链接等信息回退。优先保存来源提供的完整内容，正文、摘要、语言、文章外链与原始来源链接分开记录，并保留段落。
- 条件请求使用 ETag / Last-Modified，元数据和解析后的完整订阅窗口持久保存。收到 `304 Not Modified` 时重放窗口，再应用本次查询，支持查询变化后命中之前未匹配的内容。这个缓存只覆盖订阅返回的窗口。
- 去重依据平台身份或保守规范化后的相同链接，仅去除已知跟踪参数。不同来源命中同一条目时，追加来源观测记录及查询、频道、时间和原链接，保留主条目的身份与正文。相似标题或同一事件的不同报道不会自动合并，尚无语义新闻聚类。
- 阅读面板展示「收录与来源」，可以查看研究查询、实际发送给来源的查询及对应原链接。

公开请求继续校验 DNS、目标地址和重定向。显式配置的可信 RSSHub 可以访问其本机地址，但例外限制在该实例的地址与路径范围内，不会全局允许私网采集。

## 财经查询与来源预设

查询支持中英财经别名、`OR`、`AND`、`NOT`、括号和引号短语，并保留任意普通查询及平台操作符。X / Google 与 Reddit 分别编译为对应查询语法；本地筛选使用相同布尔含义，英文按词边界匹配。例如 `黄金 OR 美联储` 会覆盖相关中英文表达，而 `Goldman` 不因包含字符 `gold` 被归入黄金主题。主题分类仍为文本规则，不是投资判断。

新安装的默认 RSS 包包含美联储、欧洲央行、CoinDesk、Yahoo Finance、CNBC Finance 和港交所新闻稿。预设还提供美联储货币政策、TradingView 标的观点及默认关闭的 SEC 10-K Atom；SEC 需独立验证访问条件。现有订阅的名称、地址和启停状态不会自动替换，可在账号页选择加入。

可选 RSSHub 预设覆盖华尔街见闻、财联社、格隆汇、东方财富、沪深交易所、人民银行及雪球等已核实源码路由。路由存在不等于每个实例或当前网络可用；人民银行路由需要实例侧浏览器运行时，雪球本人关注需要本人 Cookie 和隔离实例。交易所公告链接可能是 PDF，未计入已提取的 HTML 正文。本项目不自动部署 RSSHub 或其他参考平台。

## 个人账号与有界采集

X 接入包括隔离浏览器登录、本人身份验证、Cookie 导入、搜索、Following、For You、作者投稿及关注名单同步。Reddit 接入包括 OAuth、订阅同步、搜索、订阅社区 / 作者投稿与账号 API 首页。连接状态区分未连接、已验证和失败；会话过期、权限不足或平台限制会显示错误，不用任务成功替代身份验证。

关注频道不使用研究关键词过滤；指定作者投稿可作为关注流的补充。采集受条数、页数、请求与时间预算限制，达到上限会提示范围有限。Reddit 推荐使用 API 的 `best`，不保证与网页推荐一致；RSSHub 服务端 X 会话尚未自动核验为本人。平台返回的互动量只参与阅读排序，不代表跨平台统一热度、资讯可信度或交易建议。

本次没有使用或真实验证个人 X / Reddit 账号。连接、分页、授权、断开、失效和错误处理通过离线模拟验证；真实账号连通性及信息流完整性仍需本人授权后验证。尚无完整历史分页回补。

## 按需正文、评论与翻译

新闻 / RSS 阅读面板的「读取文章正文」通过安全 HTTP 请求访问公开 HTML，使用新增依赖 Trafilatura 提取正文并缓存到条目中。正文提交前校验来源版本，读取期间有新内容时保留新版本并提示重试。不会绕过登录或付费墙；不能从仍停留在 Google News 聚合页的链接保证取得原文章，也不解析 PDF 公告。无法取得足够正文、超出限制或来源失败时，保留已有摘录与原链接。

Reddit / Hacker News 提供「加载评论」，按需获取有限评论并保留原评论链接及回复关系，最近结果缓存 10 分钟。Reddit 评论需要可用账号与 API 权限；X 评论尚未接入。评论加载不是全量讨论备份。

中文阅读仍通过后端配置的 DeepSeek Flash 翻译标题、摘要与已保存正文；原文保留，译文按原文版本和模型单独缓存。手动提取到的正文可继续翻译。对应文本会发送到配置的翻译服务，配置密钥仅由后端使用。
